For every interaction, choose one lesson context, one interaction (positive or negative), and one target. This file works locally in your browser; it does not upload your records.

Lesson details

Click any field, then use ← / → to move to the previous or next field and ↑ / ↓ to move between rows. Type to edit and press Enter to confirm. Use Shift + ← / → to select text.

Coding protocol

Coding form

Use ← / → to move across codes and text fields, including Time stamp, Name addressed and Notes. Use ↑ / ↓ to move to the same column in the previous or next interaction row, including Name addressed and Notes. The orange outline marks the current cell. Press Enter to select a code or confirm text. Text is selected when you enter a field with the arrow keys, so you can type to replace it. Use Shift + Enter for a new line in Notes; use Shift + ← / → to select individual characters. Mouse editing remains available.

Counts and percentages
